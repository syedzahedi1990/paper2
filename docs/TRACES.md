# Trace interventions and frozen artifacts

The crossed experiment is a comparison of two readers given the **same saved text**. Generate traces with each source checkpoint first. Run `regenerate-traces` separately with that same source checkpoint after the generated edit batch passes its preregistered sampled human audit (or individual pilot contracts are approved), then pass the resulting artifacts to both readers. `crossed` never samples a continuation. It rejects missing regenerated artifacts required by eligible controls, mismatched source checkpoints, changed source traces, altered edit contracts, and altered frozen-artifact hashes.

`question_dependent` generates a native reasoning trace for each evaluated question. `direct_fixed` generates the native trace for the rewarded direct question, then supplies exactly that text for the seven later consequences. Its generation prompt contains the direct question and base story, but no later consequence events or questions. The old `prequestion` spelling is an alias for `direct_fixed`; there is no untrained “describe the story” generation condition. Both timings remain separately identified in analysis. The original native answer is replayable only on the question from which the trace was generated.

Edit preparation uses a deterministic world selection with seed 2026. `--stage pilot` defaults to 12 worlds (192 question-dependent contracts or 24 fixed-direct contracts with two sources and eight views). This is an editing diagnostic, insufficient for ordinary confirmatory quadrant claims. **Confirmatory preparation requires `direct_fixed`** and the complete eight-view candidate panel. The default now selects all **120 candidate worlds**, providing headroom for traces that cannot be edited. For 24 trained final checkpoints plus one shared base and one clean rendering, this creates **3,000 candidate contracts**; question-dependent traces would require 24,000. Additional matched checkpoints or cue renderings increase the workload.

The 95% precision plan still requires at least **97 eligible independent worlds per arm/checkpoint** for a target half-width of .10 on a story-averaged rate, plus an observed interval meeting the target. Selecting 120 candidates does not guarantee 97 eligible worlds. The planning count is `ceil(1.96² / (4 h²))` for a rate bounded in [0,1]. This worst-case-variance normal approximation is not a guaranteed interval or a power calculation for arm differences or ratios. The manifest freezes the plan, candidate/selected world IDs and selection hash. Freeze stage, seed, precision and size before outcomes; reuse the candidate selection across sources/readers and training seeds. Shared direct traces have one contract per source artifact across views. Do not add favourable candidates until enough editable traces appear.

A fixed, preregistered editor model and prompt generate paraphrases and irrelevant edits and locate the **belief actually stated in the source trace**. The stated belief need not be correct. The editor identifies the focal character or nested character path, object, location and exact source span; the symbolic oracle computes forecasts before and after the proposed location change. Ground-truth world answers remain separate. Changed/intact edit consequences use the stated-before and stated-after forecasts. The frozen destination normally uses `scope_edit_location`; if that equals the stated location, a deterministic alternative is chosen. The destination differs from both the stated belief and world truth, preserving the intended false-premise intervention. These forecasts describe the isolated focal-belief intervention; they do not assert that every other claim in a free-form trace matches the world.

Missing, contradicted or ambiguous focal beliefs and the absence of a safe control are recorded as noneditable outcomes, with reasons and per-source/arm denominators. An empty or scientifically unusable trace need not invalidate the entire batch when that classification is itself audited. Noneditable candidates receive no targeted edit controls; their ordinary trace and applicable full-world controls remain available. Malformed JSON, truncated outputs and inference errors remain distinct `generation_failed` outcomes, with no usable targeted controls; one such outcome does not block every other contract. Original rows, candidate denominators and error records remain. Corrupted provenance, an incomplete batch and missing required human judgments still block use. Neither scientific noneditability nor generation failure may disappear from the accounting.

Existing answer statements in the source are permitted and tracked. An editor may preserve them while changing the focal intermediate claim; it may not introduce or change an answer label to manufacture compliance. Paraphrases must preserve the source's mistakes and uncertainty. Human review checks the actual stated-belief interpretation, whether only the intended fact changes, paraphrase fidelity, irrelevant-edit neutrality and forecast applicability. Machine checks alone do not establish these properties.

Generation is performed once for the whole batch and shared across readers. Audit protocol v2 preregisters a global random sample of 100 candidate contracts by default, supplemented for source/checkpoint coverage, a cap of one original sampled flaw, and an exact finite-population one-sided 95% upper error bound no greater than 5% over **all candidate contracts**. Noneditability classifications are part of this audit population. The eligible-subset bound is reported separately; the global bound is neither a 5% guarantee for eligible controls nor a per-arm guarantee. Coverage supplements do not turn the global calculation into a per-arm assurance claim.

Sampled flaws may receive human-written corrections and re-review. The original model batch, original judgments and original failure count remain unchanged; the acceptance certificate binds the effective corrected contracts and their review history. A corrected flaw still counts against the preregistered cap and error calculation. There is no model resampling until a sample passes. Unsampled generated contracts remain individually unapproved and are described as sampled quality assurance. See [the generation and sampled-review workflow](EDIT_GENERATION.md) for commands, provenance and statistical details. The editor's quality remains an empirical pilot question, and the v2 protocol requires a new frozen lineage rather than reuse of a v1 audit.

Analysis reports candidate coverage, noneditability reasons and eligible counts, conditional edit effects, and paired comparisons on common eligible story support. Eligibility can vary with source correctness or training arm; these conditional estimates are not effects over the complete candidate population. Report both the separate-arm eligible populations and the common-support population, including their denominators. Fixed seeds and views are averaged within story before whole-story bootstrap. Actual eligible story counts and intervals determine `confirmatory_precision_ready`; candidate counts alone cannot confer it. Changed/intact subgroups and paired common support may be too small even when the overall eligible pool meets the rate plan. Paired differences and ratios need their own precision assessment. No quadrant is labelled automatically; both axes and effect thresholds require review. Even a zero-width bootstrap interval from 12 identical outcomes cannot certify confirmatory precision.

Individual human contracts remain available for pilot diagnostics. Alternative manually chosen facts require reviewed forecasts and an honest oracle binding; do not retain a focal-edit binding for a different intervention. Unselected worlds retain ordinary/full-world controls.
The belief-summary control is generated automatically from the symbolic base state, including relevant physical locations and first- or second-order beliefs. The text is fixed across consequence questions; oracle answer labels are stored only in metadata, but the prose directly states the answer location for many questions. This is a positive control for using a correct premise, not a test of the model's own summary. Summary predictions are checked against ordinary targets.

Two own-trace checks are retained:

- `own_replay` uses the exact generated prefix token IDs and compares the next token to the source's ordinary continuation. This checks inference plumbing.
- `own_rerendered` rebuilds the ordinary reader prompt from decoded trace text and compares its next token to the same continuation. It also records whether its complete prefix token IDs equal the generated prefix. This detects formatting and token-boundary changes that raw replay alone cannot detect.

A forced delimiter, or a later consequence question with a different native prefix, cannot supply evidence of ordinary replay. Eligibility, ineligibility reasons, ordinary token IDs, prefix equality, and raw/rerendered answer matches are explicit fields. Token equality is reported independently of answer equality: different prefixes can coincidentally produce the same answer.
