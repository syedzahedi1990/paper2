# Trace interventions and frozen artifacts

The crossed experiment is a comparison of two readers given the **same saved text**. Generate traces with each source checkpoint first. Run `regenerate-traces` separately with that same source checkpoint after the human edit contracts are approved, then pass the resulting artifacts to both readers. `crossed` never samples a continuation. It rejects missing regenerated artifacts, mismatched source checkpoints, changed source traces, altered edit contracts, and altered frozen-artifact hashes.

`question_dependent` generates a native reasoning trace for each evaluated question. `direct_fixed` generates the native trace for the rewarded direct question, then supplies exactly that text for the seven later consequences. Its generation prompt contains the direct question and base story, but no later consequence events or questions. The old `prequestion` spelling is an alias for `direct_fixed`; there is no untrained “describe the story” generation condition. Both timings remain separately identified in analysis. The original native answer is replayable only on the question from which the trace was generated.

Human edits use a deterministic world subset selected by SHA-256 ranking with seed 2026. `--stage pilot` defaults to 12 worlds (192 question-dependent contracts or 24 fixed-direct contracts with two sources and eight views). This is an editing diagnostic, insufficient for ordinary confirmatory quadrant claims. `--stage confirmatory --precision-half-width .10` plans 97 worlds by default: 1,552 question-dependent contracts or 194 fixed-direct contracts. The count scales with additional sources, seeds and cue renderings. Review effort remains a real cost.

The confirmatory count uses `ceil(1.96² / (4 h²))` for a per-arm story mean bounded in [0,1], at 95% confidence and target half-width `h`. This worst-case-variance normal approximation is a planning aid, not a guaranteed interval or a power calculation for arm differences or ratios. The manifest freezes the plan, candidate/selected world IDs and selection hash. Insufficient pools or explicit subsets fail instead of silently shrinking a confirmatory sample. Freeze stage, seed, precision and size before looking at outputs. Reuse the same world selection across sources/readers and fixed training seeds. Shared direct traces have one contract per source artifact across views.

Analysis reports whole-story bootstrap intervals for targeted compliance, preservation and changed-response increase over the unedited trace, averaging fixed seeds and views inside each story. A per-arm rate gets `confirmatory_precision_ready` only when both planned count and observed interval meet the criterion. Small changed/intact subgroups can still fail. Paired differences are reported separately and are not covered by the rate plan. No quadrant is labelled automatically; both axes and effect thresholds require review. Even a zero-width bootstrap interval from 12 identical outcomes cannot certify confirmatory precision.

A reviewer must still approve every selected paraphrase, semantic fact edit, and irrelevant edit. With symbolic evaluation rows, preparation automatically proposes changing the focal belief to `scope_edit_location` and computes all eight predicted answers. The fact, world hash and oracle predictions are checked again before regeneration and reading. The reviewer must locate the actual text span and confirm that it expresses the proposed fact and that only that fact changes. To edit a different fact, replace the proposed semantic contract with reviewed predictions and remove its focal-edit oracle binding; do not retain a false binding. Unselected worlds retain ordinary/full-world controls. Missing selected-world contracts fail rather than silently excluding difficult traces.

The belief-summary control is generated automatically from the symbolic base state, including relevant physical locations and first- or second-order beliefs. The text is fixed across consequence questions; oracle answer labels are stored only in metadata, but the prose directly states the answer location for many questions. This is a positive control for using a correct premise, not a test of the model's own summary. Summary predictions are checked against ordinary targets.

Two own-trace checks are retained:

- `own_replay` uses the exact generated prefix token IDs and compares the next token to the source's ordinary continuation. This checks inference plumbing.
- `own_rerendered` rebuilds the ordinary reader prompt from decoded trace text and compares its next token to the same continuation. It also records whether its complete prefix token IDs equal the generated prefix. This detects formatting and token-boundary changes that raw replay alone cannot detect.

A forced delimiter, or a later consequence question with a different native prefix, cannot supply evidence of ordinary replay. Eligibility, ineligibility reasons, ordinary token IDs, prefix equality, and raw/rerendered answer matches are explicit fields. Token equality is reported independently of answer equality: different prefixes can coincidentally produce the same answer.
