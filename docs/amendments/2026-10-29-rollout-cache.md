# Technical correction: cached GRPO generation — 29 October 2026

The first disposable Mistral 24B resource profile exposed an execution bug after its step-zero development evaluation. Five profiling updates had run when the attempt was interrupted during its final evaluation. Its manifest is failed, its supervised batch is stopped, and the entire attempt remains preserved under `runs/vast-20261029/profiling`. Neither its adapter nor its timings authorize subsequent training or select a rate, model, schedule or corpus. No full candidate learning run or confirmation evaluation had started.

With TRL 0.20.0 and Transformers 4.53.2, the ordinary GRPO path calls `generate` while the model remains in training mode. When gradient checkpointing is enabled, the pinned Mistral and Qwen decoder implementations disable their cache. Generation nevertheless retains an empty cache object and slices subsequent inputs to a single new token. The result loses earlier context rather than simply recomputing the complete prefix.

A deterministic tiny-model reproduction shows four decoder calls with input lengths `[4, 1, 1, 1]` and cache lengths `[0, 0, 0, 0]`. The second-token logits equal an isolated one-token forward exactly, and differ from the correct full-prefix computation. The invalid real profiling attempt generated 40 completions, all at the full 391-token completion budget. These are technical diagnostics, not scientific learning results.

The correction switches to evaluation mode **only around rollout generation**, then restores every module's preceding training-mode flag in a `finally` block. Gradient-checkpointing settings stay enabled for optimization. Tests check growing cache lengths, equivalence to full-prefix decoding, restoration after success and exceptions, and actual GRPO training. The fixed modules, rank, optimizer settings, RNG policy, group size, trace cap, reward parser and forced-delimiter loss/attention masks are unchanged. The profile restarts from the original pinned base in a separate `profiling-v2` directory.

The three completed untrained capability panels and native development evaluator explicitly use evaluation mode, so their measurements are unaffected. Their original source and hashes remain preserved. The model decision and G0/G2 review are unchanged; G1/G3/G4 remain pending. The replacement is an implementation repair of the already-declared cached generation arrangement, not an outcome-based scientific redesign.
